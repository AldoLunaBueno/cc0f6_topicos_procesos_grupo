\subsection{Justificación}
El análisis integral del Proceso de Matrícula Regular se justifica al entenderlo como una cadena de valor secuencial y causal, donde la salida de un subproceso se convierte en la entrada indispensable del siguiente. Para proponer mejoras, resulta fundamental distinguir entre la dimensión del proceso de negocio (que define la lógica de trabajo, los actores y el cumplimiento normativo) y el sistema de información (Intranet DIRCE / SIGA-ORCE), el cual funciona como la plataforma sociotécnica que habilita y controla dichas transacciones. Modelar esta articulación completa permite comprender adecuadamente los mecanismos de control, las transferencias operativas (handoffs) y los bucles de realimentación (feedback loops) para solucionar problemas recurrentes de manera sistémica.
